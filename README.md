# Simulador de Razonamiento Abstracto UNL / CENES

Plataforma de simulación web interactiva orientada al examen de admisión de la Universidad Nacional de Loja (UNL). El banco contiene **100 preguntas vectoriales únicas** desarrolladas a partir del **Libro de Razonamiento Abstracto de CENES** (páginas 39 a 71).

## 🚀 Características
- **Tema Claro (Light Mode)**: Diseño limpio e impecable para mayor legibilidad y descanso visual.
- **Opción Correcta Aleatorizada**: Sistema automático de mezcla (shuffle) para evitar patrones repetitivos en las alternativas (A, B, C, D).
- **100 Preguntas Únicas e Interactivas**: Ejercicios parametrizados de Conteo de Figuras (16 rostros por muestra), Rotaciones (con opciones gráficas), Secuencias Horizontales, Matrices 3x3, Superposición y Analogías.
- **Gráficos SVG Nítidos**: Figuras vectoriales escalables de alto contraste integradas en código.
- **Temporizador de Examen**: Cronómetro de 60 minutos con barra de progreso.
- **Calificación en Escala UNL (1000 Puntos)**: Solucionario y reporte de rendimiento paso a paso.
