# Simulador de Razonamiento Abstracto UNL / CENES

Plataforma de simulación web interactiva orientada al examen de admisión de la Universidad Nacional de Loja (UNL). El banco contiene **100 preguntas vectoriales** desarrolladas a partir del **Libro de Razonamiento Abstracto de CENES** (páginas 39 a 71).

## 🚀 Características
- **100 Preguntas Interactivas**: Abarca Conteo de Figuras, Rotaciones, Secuencias Horizontales, Matrices 3x3, Superposición, Analogías y Secuencias Analógicas.
- **Gráficos SVG Nítidos**: Figuras vectoriales integradas para que no se deformen ni pierdan resolución en dispositivos móviles ni pantallas de alta densidad.
- **Temporizador de Examen**: Cronómetro de 60 minutos con barra de progreso interactiva.
- **Calificación en Escala UNL (1000 Puntos)**: Cálculo de resultados y desglose de aciertos/errores.
- **Solucionario Paso a Paso**: Explicación detallada de la regla lógica empleada en cada ejercicio.
